# A/B Testing & Sequential Experimentation Platform

An end-to-end experimentation platform for designing and analysing online experiments.

## Features

- Sample size estimation
- Statistical power analysis
- Sequential hypothesis testing
- Fixed-horizon A/B testing
- Automated experiment reports
- Plain-language business recommendations

## Tech Stack

- Python
- Streamlit
- Pandas
- SciPy
- Statsmodels
